# Enzo Ruffino — Portfolio

Portfolio personnel inspiré de [reza.dev](https://reza.dev/) avec un showcase projets horizontal (effet [Show-case-effect](../inspi/Show-case-effect/)).

## Stack

- React + TypeScript + Vite
- Tailwind CSS
- GSAP + ScrollTrigger + Lenis
- Three.js (lettres 3D dans la section projets)

## Démarrage

```bash
npm install
npm run dev
```

## Personnalisation

Édite `src/data/site.ts` pour :

- tes projets (titres, images, liens site/GitHub)
- ton expérience et tes passions
- tes stats hero

## Structure

- **Intro** — splash « ENZO » animé
- **Hero / About / Skills** — page principale style sidebar
- **Projects** — scroll horizontal pin + cartes
- **Experience / Passions / Contact** — footer avec liens sociaux
